## Restricciones del MVP

NO implementar:

- Cloudinary
- Push notifications
- Socket.IO
- React Native
- Multi tenant
- Configurable expiration
- Manual revoke
- Extend timer
- Diff visual
- Per item quantities

La expiración permanece fija en 20 minutos.

## Objetivo principal del producto

Permitir que un chef cree un menú permanente y envíe propuestas temporales mediante URL/QR.

El cliente podrá:

- visualizar el menú
- construir un plato visualmente
- modificar propuestas
- negociar con el chef

Las propuestas expiran automáticamente a los 20 minutos.
